# AI search skills

Free Claude skills for getting found and recommended by AI search.

## LinkedIn profile audit

A profile's job is to start conversations with buyers, not to list a career. This skill
rewrites yours around the buyer's problem, one offer and proof they trust, and makes sure
AI search engines (ChatGPT, Gemini, Perplexity) can say who you help. You get a score out
of 50, the top 3 fixes ready to paste, five headlines, a full About, and what to pin in Featured.

**Claude Code**
```
/plugin marketplace add SagelynAI/ai-search-skills
/plugin install linkedin-profile-audit@ai-search-skills
```
Then: "Audit my LinkedIn profile" and attach the PDF (Profile → More → Save to PDF).

**Claude.ai (no code)**
Create a Project, paste [prompt-for-claude-projects.md](prompt-for-claude-projects.md) into its
instructions, then upload your profile PDF.
